### 平台控件对自动化不友好的两点（实测）

1. `API KEY`（`input[type=password]`，readOnly=false、disabled=false）：
   `fill()` / 剪贴板 `paste()` 都写入 0 字符，而同表单的 Submission name 用
   同样方法能写进去 → 平台对该字段做了防程序写入处理，**必须人工输入**；
2. 任务页 `Run` / `Run latest submission`：Playwright 合成点击与原生坐标点击
   (CUA click) 均无反应，`Run history` 始终 `No task runs yet.`，无弹窗、无报错
   → **运行时也需人工点一次**。

结论：上传包、填名、选模型全部可自动化；**填 key + 点 Run 这两步留给人**。
