## 2. 平台硬规则（踩过的坑）

1. **一个任务同时只能有一个 run，且跨提交生效**：上一版的同名任务 run 没从
   Running 页消失，新版的这条任务就起不来。换版本前先确认 Running 页为 0。
2. **Run 必须用最新快照**：新上传会让旧提交变 `Superseded`，旧提交再起不了。
3. agent 非零退出时平台会自动重试（r50 重试 3 次，token 累计 57.8 万）。
4. 平台有点收尾延迟：run 页已显示 `Duration` + `STAGE 3 Failed`，历史卡片可能
   还显示 running、十几分钟后才结算分数。

## 3. 本机操作配方（in-app 浏览器）

- 不要用 `cua.getTab()`（会把整棵 AX 树打进上下文）；用
  `cua.createBrowserTab("iab", url, {visible: true})` 并把句柄存进变量复用。
- 输入必须在 visible:true 的标签上。
- 抓文字：`tab.playwright.locator("body").innerText()` 后 `.slice()` 再输出。
- 上传：`waitForEvent("filechooser")` +
  `getByText("Drop your agent code here").click({force:true})` → `fc.setFiles(path)`；
  提交名用 `pressSequentially`（`fill` 不触发 React onChange）；额度勾选框必须点
  `label.official-registration-confirm`（直接点 input 无效）。
- **起跑**：历史页的 `Run N remaining tasks` 常点不动；可靠做法是去任务页
  （`/competitions/hackathon/tasks/hackathon--github`）点 `Run latest submission`
  （`press("Enter")` 或 `click({force:true})`，CDP 报超时不代表没生效，事后读
  `/running` 确认）。
- 打包：robocopy `arcbench/agent` → `arcbench/runs/stage-rNN`（排除
  node_modules/dist），再 `Compress-Archive -Path "$stage\*"` → `arcbench/dist/arc-agent-rNN.zip`。

## 5. 已经定位的因果链（非常重要）

r55 的 Stdout 逐轮记录：

```
[selfcheck] exact-name coverage: 140/173 present (33 missing)
[rehearsal] seeded sign-in probe: ... `/auth/sign-in` username -> 404 …
[rehearsal] FAILED → repair turn wrote 3 file(s)
[rehearsal] seeded sign-in probe: /auth -> 404 x3 → repair turn wrote 1 file
[rehearsal] seeded sign-in probe: /auth/username -> 401 x3   ← 接口有了但登录被拒
[rehearsal] giving up; submitting as-is
```

需求里每条场景的 WHEN 都是 "**signs in as alice-dev with Valid-password-123!**"，
GIVEN 是"从未登录首页开始"。所以**登录这一步失败 = 100 条全挂**，而 app 依然
构建成功、启动成功、名字覆盖 83%。

配套事实：

- GitHub 需求包 124 处写着
  `the seeded data is account alice-dev, email alice.dev@example.test, password Valid-password-123!`，
  以及 `organization Acme Demo`、`repository acme-docs`/`secret-research`、
  `member bob-reviewer`、`team frontend-team`、`branches main/feature-search`。
- Sheet 需求包用另一种句式（`seeded` 400 次、`Q3 Sales` 322 次）：
  `The evaluation seed contains the seeded workbook Q3 Sales, worksheet Sheet1, and cell A1 value Region`。
