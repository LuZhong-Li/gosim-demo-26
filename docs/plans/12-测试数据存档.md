## 4. 已知风险点（可能影响真实通过率）

来源：[README 已知局限](../../README.md) 与 [docs/dev/limitation.md](../dev/limitation.md)，
旧「demo+视频」提交模型下刻意保留，未随本轮修复：

- 团队权限采用“并集”语义：与 admin 同队的 member 会继承 admin 权限（P001 判定过宽）；
- PR 审批未校验自审批与审批人身份，已合并 PR 可重复合并；
- `required-check` 取全局最新一条工作流运行记录，多 PR 间会串扰；
- 成员/团队允许重名。

若平台验收用例覆盖“权限隔离”或“多 PR 各自 required-check”，上述行为会被判失败，
是提升真实 GUI 通过率时最优先的处理对象。
