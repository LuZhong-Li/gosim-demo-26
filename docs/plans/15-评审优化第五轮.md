## Global Constraints

- `main` 保持冻结基线；本轮全部代码提交落在 `codex/dev`，验证通过后再合回 `main`。
- 测试一律使用 `tmp_path`，不得改写 `demo/output/trace.jsonl`、
  `demo/seed-workbook.xlsx`；Web 交互 trace 一律写入独立路径
  `demo/output/trace-web.jsonl`（不入库）。
- Web 层不新增运行时第三方依赖（只用标准库）；`api/web/agent` 只调
  `ServiceBus`，`services/core` 不依赖 Web 层。

  （复用 P001/R001/B001/WEB400/WEB404）。
- 优化顺序固定为：GUI 通过率 > Token 效率 > 完成时间。
- 9/7 样例检查点：样例若到，先按 14 §2.2 归档并复审本计划范围；
  展示层任务照常收尾，S2+ 范围以样例为准。
- GUI 验收不依赖真实浏览器：HTTP 端到端 + HTML/JS GUI-hook 断言
  （沿用 14 §5「本机无浏览器可手动冒烟」的控制方式）。
