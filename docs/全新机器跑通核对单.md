# 全新机器跑通核对单（提交物 1：可运行的复刻）

> 目的：在全新机器上从空目录把 GX-Sheet 跑通（CLI + Web），证明
> 「源码 + 启动方式」可复现。预计 10 分钟内完成（不含可选的全量测试 ~70s）。
> 前置：Windows PowerShell、Python 3.11–3.14、网络可访问 PyPI / GitHub。

## 0. 拿到源码

```powershell
git clone <你的公开仓库 URL> gosim-demo-26
cd gosim-demo-26
```

若用压缩包交付：解压后进入 `gosim-demo-26/` 目录即可，后续命令不变。

## 1. 环境自检

```powershell
python --version
```

Expected：`Python 3.11.x` / `3.12.x` / `3.13.x` / `3.14.x` 任一。

## 2. 创建虚拟环境并安装依赖

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pip install -e .
```

Expected：pip 安装成功，无报错；`gx` 命令在虚拟环境内可用。

## 3. 环境预检

```powershell
.\.venv\Scripts\python.exe tools\check_env.py
```

Expected：输出 Python、openpyxl、pydantic、typer 版本符合环境要求。

## 4. 生成种子（组织 xlsx）并清空旧 trace

```powershell
.\.venv\Scripts\python.exe demo\init_seed.py
```

Expected：输出种子已生成与
`角色 4 个 / 团队 1 个 / 成员 2 个 / 工作流 1 个`。

> ⚠️ 该命令会重写 `demo/seed-workbook.xlsx`（时间戳）并删除旧
> `demo/output/trace.jsonl`；仅做复现验证时没问题，恢复仓库基线见第 8 步。

## 5. CLI 冒烟

```powershell
.\.venv\Scripts\gx.exe member list
```

Expected：列出 `admin`（admin）与 `alice`（member）两行。

## 6. 一键完整链路（核心演示）

```powershell
.\.venv\Scripts\python.exe demo\run_demo.py
```

Expected：9 个环节依次输出 `[OK]` / `[EXPECTED]`，最后
`[OK] trace 校验通过`。`[EXPECTED]` 是设计内的权限/规则拒绝路径，不是错误。

## 7. Trace 校验

```powershell
.\.venv\Scripts\python.exe tools\check_trace.py
```

Expected：`[OK]`，共 10 条事件，类型统计为
`api_call=6, human_intervene=1, prompt=1, tool_call=1, workflow_run=1`。

## 8. Web 形态（可选，展示层）

```powershell
.\.venv\Scripts\python.exe -m web.run --reset
```

另开浏览器访问 `http://127.0.0.1:8765/`，或命令行验证：

```powershell
Invoke-WebRequest http://127.0.0.1:8765/api/meta | Select-Object StatusCode
```

Expected：`200` 与 JSON `ok: true`；结束后在服务终端按 `Ctrl+C` 停止。

> Web 写入 `demo/output/trace-web.jsonl`，不影响正式 trace。

## 9. 全量测试（可选）

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

Expected：`170 passed`，0 failed（约 60–75s）。

## 收尾与基线恢复

复现验证后若不需要保留本次生成结果：

```powershell
git restore --source=HEAD -- demo/output/trace.jsonl demo/seed-workbook.xlsx
```

若准备把本次运行作为正式提交轨迹（须与 Demo 视频同一次录制），不要执行上面的
恢复命令，而是提交新的 trace 并 push。

## 常见问题

- 端口 8765 被占用：`Get-NetTCPConnection -LocalPort 8765 -State Listen` 查看，
  或换端口 `python -m web.run --reset --port 8766`。
- `gx` 找不到：确认已执行 `pip install -e .`，并使用 `.\.venv\Scripts\gx.exe`。
- PyPI 不可达：评审沙箱按平台说明预装依赖；本地需先解决网络再安装。
